Use it from your agent

Public and rate limited — 20 req/min without a key. JSON by default, or paste-ready Markdown with format=md, ending with instructions for your agent to record what's done and what's pending in your project.

Add project=<id> to a search to see what you already shipped, and hide=done to skip it.
curl "https://<this-site>/api/v1/requirements?category=messaging&max_priority=2&include=tests,accelerators&format=md"
Prefer the terminal?airedb CLI
The airedb CLI (reqdb.mjs) is one file, no dependencies: pull requirements into your repo, let your agent mark progress, and fail CI while P1 work is pending.
node reqdb.mjs pull
